# سیستم مدیریت سوپرکولا

سیستم مدیریت یکپارچه شرکت سوپرکولا با رابط کاربری فارسی، راست‌چین و
واکنش‌گرا.

## امکانات

- داشبورد مدیریتی با خلاصه فروش، سفارش‌ها و موجودی
- مدیریت محصولات و دسته‌بندی کالاها
- مدیریت مشتریان و سفارش‌ها
- مدیریت موجودی و ورود کالا به انبار
- مدیریت کارکنان و سطح دسترسی کاربران
- گزارش‌گیری و دریافت خروجی اطلاعات
- طراحی سازگار با موبایل، تبلت و دسکتاپ

## بخش‌های سیستم

این سیستم بخش‌های زیر را در اختیار مدیران و کارکنان قرار می‌دهد:

- داشبورد
- سفارش‌ها
- محصولات
- مشتریان
- انبار
- گزارش‌ها
- تولید
- نمایندگی‌ها
- حاضری
- معاشات
- موترها
- کاربران
- لاگ رویدادها

## اجرای پروژه

برای مشاهده سیستم، صفحه ورود را باز کنید:

```text
login.html
```

پس از ورود، هر کاربر بر اساس سطح دسترسی خود به بخش مربوط هدایت می‌شود.

## ساختار پروژه

```text
assets/   تصاویر و نشان‌های تجاری
css/      فایل‌های طراحی و قالب‌بندی
js/       منطق برنامه و مدیریت داده‌ها
pages/    صفحه‌های داخلی سیستم
```

این پروژه با HTML، CSS و JavaScript خالص ساخته شده و برای انتشار در وب
و ارائه به مشتری آماده است.
